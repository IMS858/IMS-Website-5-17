# IMS website reconciled release

Owner authorized production release of the previously preview-only website work and chatbot metrics on September 28, 2026. This candidate combines main's GA4 installation with the reviewed organic-growth (PR1), website/privacy hardening (PR2), and contact-delivery (PR3) code. Earlier dated documents remain historical checkpoints, not current deployment claims.

Preserved: existing URLs, real image assets, Vagaro booking widget/fallback, public prices/copy outside the reviewed organic improvements, Coach OS client login, GA4 opt-in and privacy exclusions. No Vagaro scheduling/settings were changed.

Added chatbot metrics: fixed event names for opens, sends, rendered answers/errors, three preset-topic selections, and exact booking/contact/phone link clicks. These are interaction counts, not leads, unique people, purchases or raw transcripts. Consent key v2 requests fresh consent for this expanded measurement. Events before consent or tag load are discarded; no retrospective capture. Up to 50 events per eligible page. No form answers, health details or identities enter analytics. Google Enhanced Measurement and account-side settings still require owner review; the source-code whitelist is not a claim about every upstream configuration.

Contact reconciliation deliberately replaces PR3's unconditional form-action switch with progressive enhancement. The HTML form stays on Web3Forms until GET /api/contact reports direct_delivery=true. Production requires IMS_CONTACT_SEND_ENABLED=true, website-scoped RESEND_API_KEY, verified RESEND_FROM_EMAIL and a valid inbox. Preview has its own IMS_CONTACT_PREVIEW_SEND_ENABLED gate. No key or sender is inferred from Coach OS's separate project. Before enabling direct delivery, verify production anti-abuse controls, sender/domain, controlled recipient delivery, paired IMS_COACH_OS_SYNC_URL and IMS_WEBSITE_SYNC_SECRET. The API returns only a configuration boolean, never secrets or a false inbox-delivery claim. An ambiguous send is retried with unchanged in-memory fields; it never automatically falls back to a second provider. Existing contact access works without JavaScript. No test emails or hosted inquiry records are sent by CI.

The unified workflow parses every JS source and runs all inherited/new website, contact, chat, privacy and analytics tests. The unchanged shared animation/navigation tail is hash-verified. Source archives capture exact tested heads; no skipped tests. Actual preview/mobile acceptance and final production alias SHA must be checked before claiming deployed. A READY deployment and successful static fetch do not prove GA4 ingestion or email delivery.

The separate standalone Python generator and Coach OS have their own releases, credentials and checks. This website commit cannot configure or verify their service authentication. Do not blindly promote an old generator deployment or weaken exercise safety to make a program generate.
